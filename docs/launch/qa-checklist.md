# AWP 本番用 QAチェックリスト（全機能・スマホ375px）

ローンチ前に「本番環境で、はじめての人が迷わず使えるか」を確認するためのチェックリストです。
画面名・ボタン名・メッセージは、実際のコード（`frontend/src/app`、`backend/src/routes`）から拾っています。

- 項目数: 93 項目
- 所要時間の合計（目安）: **335分（約5時間35分）**（各項目の【N分】の合計。ログインのやり直しや待ち時間は含みません）
- 担当: tetsu / kei（二人で分担するときは、項目番号で分けてください）

## このチェックリストの使い方

1. 上から順にやる必要はありません。ただし **「0. 準備」だけは最初に** やってください。
2. 終わった項目は `- [ ]` を `- [x]` に書き換えます。
3. おかしかったところは、項目の番号（例: `D-3`）・画面のスクリーンショット・やった手順を課題に書いてください。
4. **本番で個人情報・お金に関わる操作** には「⚠️ 本番注意」を付けています。必ず「テスト用の値」と「後片付け」を読んでから始めてください。

### 確認する画面サイズ（すべて 375px）

すべての項目で、**幅375px（iPhone SE / 12 mini 相当）** で確認します。やり方は次のどちらかです。

- **実機のスマホ**（いちばん確実。Safari と Chrome のどちらかでOK）
- **パソコンの Chrome**: 右クリック → 「検証」→ 左上の「デバイスツールバー」（スマホのアイコン）→ 上のバーで幅を `375` にする

> 項目の「📱375px」は、そのサイズで次の3つを見る、という意味です（毎回書くと長いので、ここにまとめます）。
> 1. **横スクロールが出ない**（画面を左右に動かせてしまう場合は不具合）
> 2. **文字が不自然な位置で折り返さない**（1文字だけ次の行に落ちる、ボタンの文字が2行に割れる、など）
> 3. **ボタンが指で押せる**（下の「ホーム／発見／機能／ツール／見てみる」のタブバーに隠れて押せないボタンがない）
>
> 項目に別の注意があるときは、その項目に書いてあります。

### テスト用の値（本番で使うもの）

| 何に使う | 使う値 | 注意 |
| --- | --- | --- |
| メールアドレス | 自分が受信できるアドレスの `+` 付きエイリアス（例: 自分のアドレスの `@` の前に `+awpqa1` を足す）など | 他人のアドレス・実在の知らない人のアドレスは使わない。`+` が使えないメールの場合は、QA専用のアドレスを1つ用意する |
| パスワード | QAのたびに新しく作った8文字以上のもの（他のサービスと同じものは使わない） | 課題・チャット・コミットには**絶対に書かない** |
| 携帯電話番号 | 自分の携帯（070 / 080 / 090 で始まる番号） | SMSの確認コードが本当に届きます。同じ番号は1つのアカウントにしか使えません（`この電話番号は既に別のアカウントで使われています`）。10分に3回までしか送れません |
| ページのURL（スラッグ） | `qa-` で始まる名前（例: `qa-0101-tetsu`）。半角英小文字・数字・ハイフンで3〜40文字 | 本番で他の人に見えるので、`qa-` を付けて見分けられるようにする |
| お店・活動の名前、キャッチコピー、強み | 「QAテスト用」と分かる文言 | 実績・特典の欄は**空のまま**にする（事実でない実績を書くと景品表示法に触れるおそれがあるため） |
| お客様の名前・連絡先（予約・注文・チャットボット） | 名前は「QAテスト」、連絡先は自分のメールアドレス | 実在の他人の名前・電話番号・住所は入れない |
| 住所（注文の配送先） | 郵便番号 `100-0001`、住所は「QAテスト用（発送しないでください）」 | 本当に送る必要がないことを注文の「メッセージ」にも書く |
| 銀行口座（ショップ設定・プランの振込先） | 管理者は**本番の本当の口座を入力しない**。確認は「入力欄が出る・保存できる」までにして、保存したテスト口座はあとで必ず消す／空にする | 口座番号は暗号化して保存されますが、課題・スクリーンショットに写さない |
| カード情報 | **使わない**。このチェックリストにカードを入力する項目はありません | 決済は Stripe のホスト型のみ。AWPはカード情報を扱いません |
| 外部サービスのキー（LINE・Harness の APIキーなど） | テスト用のものがない場合は、その項目は「入力欄と注意書きの確認」までにする | 本番の本物のキーを入れたら、確認後に必ず「解除」する。キーを課題・スクリーンショット・コミットに残さない |

### 後片付けの基本（QAが終わったらやること）

1. **QAで作ったページ・商品・投稿・予約・注文は、各項目の「後片付け」で消す**（本番の「発見」や「タイムライン」に残さない）。
2. **QAで作ったアカウント**: Webの画面にはアカウント削除のボタンがありません。プライバシーポリシーでは、スマホアプリの「設定」→「アカウントを削除」で、アカウントと関連データ（ページ、プロフィール、投稿、商品、予約リクエスト、LINE連携情報、お問い合わせ履歴）を削除できると案内しています。**アプリで削除するか、アプリを使えない場合は運営者に「このメールアドレスのアカウントを削除してください」と頼んでください**。削除すると有料プランも自動で解約され、未使用のキャッシュは失効します。
3. 最後に、**「発見」（`/discover`）と「タイムライン」（`/feed`）で `qa-` や「QAテスト」の文字が残っていないか** を確認する。
