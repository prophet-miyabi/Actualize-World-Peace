# AWP を SNS として設計し直す（2026-10-13）

## 前提
AWP の北極星（[vision.md](vision.md)）: 世界人口の大半が参加するソーシャルネットワークへ成長し、参加者が生む余剰を参加配当として配る。
これまでの AWP は「ページを作る道具」が中心で、SNS（発見・タイムライン・フォロー）は後付けだった。設計の中心を **人（プロフィール）→ つながり → 参加の記録 → 分配** に置き換える。

## 設計の原則
1. **人が中心**: 入口はタイムライン、帰る場所はマイページ。ページ・商品・予約は「その人が持っているもの」
2. **投稿は会話**: いいね・返信・共有を全画面で同じ形に。通知で返ってくる
3. **参加は記録される**: 投稿・返信・もらったいいね・フォロー・ページ公開・紹介・注文を Contribution として事実で残す。これが将来の参加配当の根拠（配り方は会議室の未決 U1）
4. **自治単位へ拡張できる構造**: フォローは個人間、ページは個人の所有。次の段階で「コミュニティ（自治単位）」を人とページの上に置く
5. **信頼の基礎**: 退出・データ持ち出し・通報・非公開をいつでも見つかる場所に。推薦は単一指標で最適化しない

## 情報設計（スマホの下部タブ）
| タブ | 画面 | 中身 |
|---|---|---|
| ホーム | `/feed` | タイムライン（みんな／フォロー中）、投稿、ページがない人への最初の一歩 |
| 発見 | `/discover` | おすすめ・新着・人気・フォロー中・カテゴリ（ページと人） |
| 作る（中央） | `/create` | AIとおしゃべり／4ステップ／投稿／商品／予約／プロフィール |
| 通知 | `/notifications` | フォロー・いいね・返信・予約・注文・プラン（未読バッジ） |
| マイページ | `/me` | あなた・参加の記録・あなたのページ・管理への入口・自分の投稿 |

ログイン後の着地は `/feed`。ダッシュボード（`/dashboard`）は「ページの管理」としてマイページの下に置く。

## データモデル（第1段）
- `PostLike(userId, postId)` 投稿へのいいね
- `Comment(id, postId, userId, body, hidden)` 返信（1階層）
- `Notification(id, userId, type, title, body, href, actorId, readAt)` アプリ内通知。`notifyUser()` がプッシュと同時に保存するため、予約・注文・プランの既存通知も自動で入る
- `Contribution(id, userId, kind, points, refId)` 参加の記録（post 2 / comment 1 / like_received 1 / follow_received 2 / page_published 5 / referral 10 / order_completed 5）

## API（第1段）
- `GET /api/posts/:id`（返信つき）、`POST/DELETE /api/posts/:id/like`、`POST /api/posts/:id/comments`、`DELETE /api/posts/comments/:cid`
- `GET /api/posts/me/summary`（マイページ）
- `GET /api/notifications`、`GET /api/notifications/unread`、`POST /api/notifications/read`
- フォロー・ページいいね・返信・投稿いいねで通知と参加の記録が発生

## 段階
| 段階 | 内容 | 状態 |
|---|---|---|
| 1 | 下部タブの再設計、投稿のいいね・返信・共有、通知、マイページ、参加の記録 | **実装（2026-10-13）** |
| 1.5 | **SNSの柱**: リール動画／文章＋写真・動画の投稿（`/reels`、`PUT /posts/:id/video`）、投稿のまとめ＝プロフィール、ページへの「最新の投稿」自動埋め込み（`postsEnabled`）、投稿→作った人のページ導線、全公開ページに必ず入る AWP へ戻るボタン（`AwpHomeBar`） | **実装（2026-10-13）** |
| 2 | 人の発見（おすすめユーザー）、ハッシュタグ、再投稿、投稿へのページ添付、DM（要: 通報・ブロック） | 次 |
| 3 | コミュニティ（自治単位 v0）: 参加・投稿・規則・運営者、分断指数の計測 | 会議室 U2 の後 |
| 4 | 参加配当の表示（余剰の会計の公開、あなたの取り分の見込み）— 資金移動業の登録と並行 | 2027 |

## SNS の柱（オーナーの定義・2026-10-13）
1. 投稿はリール動画、または文章＋動画/画像。一人の投稿はプロフィール（/ユーザー名）に一つにまとまる
2. 投稿する人は、自分のページ（HP/LP）に「最新の投稿」を組み込める。投稿するたびに自動で更新される
3. 投稿を見た人が作った人のページへ飛ぶと、その人の HP/LP に行ける（投稿カードの「ページ →」、プロフィールの「ページを見る →」）
4. AWPで作成・公開された全ページに、AWPの主軸（ホーム）へワンタップで戻るボタンを必ず入れる（持ち主は外せない。独自ドメインでも本体へ）

## 守ること
- 数字（利用者数・いいね数）を作らない。ランキングは事実の集計のみ
- ダークパターン禁止（[behavioral-design.md](behavioral-design.md)）
- 投稿・返信は本文をテキストとして表示（HTMLとして解釈しない）。通報は全ての投稿・返信・ページ・プロフィールに
