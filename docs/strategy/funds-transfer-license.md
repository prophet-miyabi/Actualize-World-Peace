# 第三種資金移動業の登録（2027年中）— 収益を利用者に配分できるようにする

> オーナーの決定（2026-10-13）: **2027年中に第三種資金移動業の登録を取得し、収益を利用者に配分することを可能にする。**
> 正しくは「認可」ではなく **登録**（資金決済法）。登録先は本店所在地を管轄する財務局。
> 法律の詳細は必ず弁護士・行政書士・財務局の事前相談で確認する（この文書の「要確認」は推測ではなく確認が必要という印）。

## なぜ必要か（整理）
- AWP が**自分の収益**を利用者に払う（参加配当・紹介報酬）だけなら、原則として資金移動業ではない（AWP の支払債務の履行。源泉徴収・支払調書など税務は要確認）。
- しかし AWP が目指す「利用者のキャッシュ残高を**現金として出金**できる」「利用者間で送れる」形は、**為替取引**に当たる可能性が高く、資金移動業の登録がないとできない（要確認）。
- 第三種は **1件 5万円以下** の送金に限る類型で、小口の配当・報酬の出金に適する。将来、上限を超える送金が必要なら第二種（1件100万円以下）を検討。

## 登録の主な要件（資金決済法・内閣府令。要確認）
| 要件 | 内容 | AWP の現状 → 必要な対応 |
|---|---|---|
| 法人格 | **株式会社**（または同等の外国法人）であること | 個人事業なら法人化が前提 |
| 財産的基礎 | 業務を適正に行う財産的基礎（第三種は第二種より軽い。純資産など） | 資本金・純資産の計画 |
| 利用者資金の保全 | 第三種は **履行保証金の供託** か **預金等による管理**（分別管理＋外部監査）を選べる | 銀行口座の分別管理＋監査法人の選定 |
| 滞留の制限 | 送金に関係のない資金を受け入れない・滞留させない（上限管理） | キャッシュの仕様変更（用途・期限・上限） |
| 体制整備 | 内部管理、コンプライアンス、システムリスク管理、情報セキュリティ、苦情対応、利用者保護 | 規程類の整備、責任者の配置 |
| 犯収法 | 取引時確認（KYC）、疑わしい取引の届出、記録保存 | 本人確認（eKYC）の導入 |
| 業務方法書・契約 | 業務方法書、利用規約、利用者への情報提供 | 法務で作成 |
| 協会 | 日本資金決済業協会への加入（実務上ほぼ必須） | 加入手続き |
| 情報提供 | 標識、報告書、帳簿 | 運用体制 |

## 2027年中の登録に向けたロードマップ（案）
| 時期 | やること | 担当 |
|---|---|---|
| 2026-11 | 弁護士・行政書士（資金決済法の実績）を選定。**財務局の事前相談**の予約。法人化の判断 | オーナー・legal |
| 2026-12 | 事前相談（1回目）。要件の確定。資本・保全方法（供託 or 預金管理）の選択 | オーナー・legal・finance |
| 2027-Q1 | 法人設立／増資。規程類（内部管理・AML・システムリスク・苦情対応）の作成。eKYC の選定 | legal・security・engineering |
| 2027-Q2 | キャッシュ機能の設計変更（分別管理・上限・滞留防止・出金）。監査法人の選定。業務方法書 | engineering・finance |
| 2027-Q3 | 申請書類の提出。審査対応（追加資料・システム説明） | legal・engineering |
| 2027-Q4 | **登録**。協会加入。出金機能の公開。参加配当の初回支払い | 全員 |

## 指標（会社の目標として登録）
- 事前相談の実施（2026-12-31）
- 法人・資本・保全方法の確定（2027-03-31）
- 申請書類の提出（2027-09-30）
- 登録の取得（2027-12-31）
- 登録後: 出金可能な利用者数、初回配当の支払い件数

## 会議室で扱う問い（追加）
- 配当の「原資比率」と「均等部分」（U1）は、登録のスケジュールと合わせて 2027-Q2 までに決める
- 登録までの間、キャッシュは「AWP の有料機能の支払い専用」のままにする（現金化しない）
