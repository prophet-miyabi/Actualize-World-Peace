# AWP のビジョン（北極星）v2026-10-12

> 正本は `backend/src/company/vision.ts`（エージェントが `company/vision` として読む）。

## 目的
**世界平和の実現（Actualize World Peace）。**

## 到達点（オーナーの構想）
1. AWP は、世界人口の大半が参加するソーシャルネットワークへ成長する
2. その上で生まれる余剰を参加者に配り、ユニバーサル・ベーシックインカム（UBI）に相当する所得の土台を作る
3. そのために、膨大な実行エージェント群を統括する超知能（AWP Intelligence）を実現する

## 「獲得すべきもの」の再定義（2026-10-12 第1回 AWP 会議室）
これまでの前提（登録ユーザー数の獲得）は手段であって目的ではない。AWP が獲得すべきものは次の4つ。
1. **信頼（legitimacy）** — 透明な規則、退出の自由、約束を検証できる仕組み
2. **参加者が生む価値の総量（surplus）** — ページ・取引・紹介・AIの生産性が生む余剰
3. **余剰を配る正当な仕組み（dividend mechanism）** — 法に適合し、貢献と公平のあいだで設計された配当
4. **自壊しない統治（resilient governance）** — 入れ子の自治、分断を増幅しない設計、超知能への人間の歯止め

ユーザー数（100万人）は、この4つが機能しているかを測る**中間指標**として残す。

## 言葉の定義（測れる形）
- **超知能（AWP Intelligence）**: ここでは「人間の承認のもとで、多数のエージェントに仕事を割り当て、結果を検証し、学習して次の割り当てを改善する統括系」。独立した意思や自己目的は持たない。評価は「人間の判断を要する決定を正しく人間に戻せたか」「検証で誤りを見つけられたか」で行う。
- **UBI 相当**: 民間プラットフォームが行うものは制度としての UBI ではなく「参加配当」。評価は「配当を受けた人の生活の不安の低減」と「配当の原資が持続可能か」で行う。
- **全人類規模**: 単一の中心では統治しない。地域・言語・目的ごとの自治単位が連なる連合体として設計する。

## 段階
| 段階 | 到達 | 測るもの |
|---|---|---|
| 0（2026-10〜） | 日本で、ひとりで始める人が自分の手でウェブ上のシステムを作れる | 公開数・7日継続・紹介比率 |
| 1（2027） | 参加者が生む余剰を可視化し、最初の「参加配当」を法に適合した形で試す | 余剰総額・配当を受けた人数・原資の持続性 |
| 2（2028〜） | 自治単位の連合（地域・言語）と、エージェント統括系の外部監査 | 自治単位数・監査の合格・紛争解決の件数 |
| 3 | 世界規模の協調課題（気候・災害・宇宙利用）への参加者の集合行動 | 課題ごとの参加・成果 |
