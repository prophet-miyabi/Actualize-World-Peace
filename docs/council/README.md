# AWP 会議室

オーナーの大きな問いを、5人の博士（心理学・社会学・経済学・地政学・天文学）と議長で議論し、**要件・決定・次の一手**に落とす場。
Claude Code で `/awp-council <議題>` と打つと開く（博士はサブエージェント `.claude/agents/awp-council-*.md`）。

## 導線
議題 → 5人の見解（並列） → 対立点 → 合意／未決／次の一手 → 議事録（この下） → 会社メモリ `council/*` → **タスク**（AI企業の担当へ）／**クルーのタスク**（人の作業へ）

## 未決の問い（優先順）
1. 参加配当の原資と配り方（経済学・法務）— 法的な器は決定: **第三種資金移動業の登録を2027年中に取得**（[計画](../strategy/funds-transfer-license.md)）。残りは原資比率・均等部分・税務
2. 自治単位の最小単位（社会学）— 地域か、言語か、目的か。最初の1単位を日本でどう作るか
3. 統括系（超知能）の人間の歯止め（地政学・心理学）— 誰が、何を、いつ止められるか。外部監査の形
4. 平和の指標（地政学・天文学）— AWP の活動が「平和に近づいた」ことを何で測るか
5. 参加者の尊厳と自律の設計（心理学）— 配当が「施し」ではなく「権利」として体験される条件
