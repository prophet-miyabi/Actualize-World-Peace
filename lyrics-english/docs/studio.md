# 歌詞スタジオ(歌詞 → 解説・教材・英語+和訳の歌詞動画)

画面録画は使いません。**歌詞テキスト + 音源**から、よくある「和訳つき歌詞動画」を直接生成します。
ffmpeg と yt-dlp があれば PC・Pixel(Termux)のどちらでも動きます(adb は不要)。

## 流れ(担当エージェントの分業)
```
あなた ──歌詞を貼る──▶ ディレクター(対話窓口)
                         ├─ 歌詞解説担当 : 日本語訳 / テーマ・背景・難所の解説 → explanation.html
                         ├─ タイミング担当: 音源を探して取得 → 各行の時刻を付ける
                         ├─ 動画編集担当 : 背景画像を選ぶ(画像を見比べる)→ 英語+和訳が同時に出る動画 → 仕上がりを目視確認
                         └─ 教材作成担当 : 単語・フレーズ・文法・クイズ → lesson.html / anki_vocab.tsv / quiz.md
        ◀─ 成果物 ─┘   「訳をもっと詩的に」「時刻が早い」「背景を変えて」→ 該当担当だけやり直し(ループ)
```

## 使い方(Discord)
1. `!setup` で `lyrics-studio` チャンネルを作る(ボットに「チャンネルの管理」権限が必要)。
2. `lyrics-studio` に、**曲名・アーティストと歌詞**を貼る。長い歌詞は `.txt` を添付してもよい。
   例: `Test Band の "Paper Sea" です。` + 歌詞
3. 数分で、解説・動画・教材が届く。続けて「次の曲」「1行目の訳を直して」「時刻が全体に0.5秒早い」「背景をアーティスト写真に」などと言えば、その担当だけが直す。

## 使い方(CLI・Discord なし)
```
python -m lyriclearn studio --title "Paper Sea" --artist "Test Band" --lyrics-file lyrics.txt
```
成果物は `work/studio/<曲>/` に出る(`lyrics_video.mp4`、`explanation/`、`lesson/`)。

## 時刻合わせの仕組み(動画の精度を決める所)
1. **LRCLIB**(時刻つき歌詞の無料サービス)から取得し、入力した歌詞の各行に順番を保って対応づける(対応率が good ≥ 80% / fair ≥ 50%)。
2. 見つからなければ **音声認識**(`pip install faster-whisper` 済みの PC のみ)で歌い出しを検出して対応づける。
3 それも無理なら**文字数に比例した推定**(poor・不正確)。このときディレクターが必ず伝えるので、
   LRC 形式の時刻つき歌詞を貼ってもらえれば `manual` でやり直せる。

## 日本語フォント
ASS 字幕で描画します。Android は `/system/fonts` の Noto Sans CJK、Linux/Windows は fontconfig/システムフォントを使います。
日本語が四角(□)になる場合は、日本語フォント(例: Noto Sans CJK JP)を入れてください。

## 注意
- 歌詞は**あなたが入力したもの**を使い、解説・訳もそれに基づきます。個人利用の範囲で使ってください。
- 時刻つき歌詞(LRCLIB)の本文はモデルや画面には出さず、行の対応づけにだけ使います。
