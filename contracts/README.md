# 受託開発の契約・提案ドキュメント生成（contracts/）

LP・HP・Webアプリ・業務システムの受託（個人事業主＝乙 → 法人・個人の顧客＝甲）で使う、契約書・仕様書・提案書の一式を、案件ごとのJSONから生成します。顧客への「安全性・正常稼働への配慮」と、受注者の「法的リスクの防衛」（請負と準委任の切り分け、契約不適合責任の期間制限、損害賠償の上限、免責、権利の留保と利用許諾）を両立する構成です。経済産業省「情報システム・モデル取引・契約書」と IPA「中小企業の情報セキュリティ対策ガイドライン」の考え方に沿っています。

## 構成

```
contracts/
  generate.js                 生成スクリプト（Node 18+、依存パッケージなし）
  projects/sample_client.json 案件の設定サンプル（富士住設サービス）
  templates/                  テンプレート（{{変数}} を置換）
    01_業務委託基本契約書_兼_NDA.md
    02_開発個別契約書_兼_発注仕様書.md
    03_システム検収完了確認書.md
    04_システム保守運用仕様書_SLA定義書.md
    05_情報セキュリティ対策基準書_顧客提示用.md
    06_営業提案用_保守プラン料金表とFAQ.md
  output/                     生成物（Git には入れない）
```

## 新規案件のときの使い方

1. 案件ファイルを作る（サンプルをコピーして値を書き換える）

```bash
cp contracts/projects/sample_client.json contracts/projects/顧客名.json
```

主な項目: `client_name`（顧客名）、`project_type`（`LP` / `HP` / `WebApp` / `System`）、`project_name`、`scope`（開発範囲）、`deliverables`（納品物）、`exclusions`（範囲外）、`dev_fee`（税別の開発費）、`payment_terms`、`delivery_date`、`inspection_days`（検収日数、既定10）、`warranty_months`（保証月数。既定は LP 1 / HP 2 / WebApp 3 / System 3）、`liability_cap_months`（保守の賠償上限の月数、既定6）、`maintenance_plan`（`light` / `standard` / `premium`）、`maintenance_fee`、`contractor_*`（受注者情報）、`jurisdiction_court`（乙の所在地を管轄する裁判所）。省略した項目は `generate.js` の既定値が使われます。

2. 生成する

```bash
node contracts/generate.js contracts/projects/顧客名.json
```

`contracts/output/顧客名_YYYYMMDD/` に、6つの Markdown と、同名の印刷用 HTML、まとめて印刷できる `00_全書類まとめ.html`、置換に使った値 `_variables.json` ができます。未置換の変数があれば警告が出ます（終了コード 2）。

3. 確認する

Markdown を読んで、案件固有の条件（範囲外、支払条件、特記事項）が意図どおりか確認します。文面の修正は `templates/` 側で行えば次回以降にも反映されます。

## PDF にして顧客へ送る手順

1. `00_全書類まとめ.html`（または個別の `.html`）をブラウザ（Chrome / Edge）で開く。
2. 右上の「印刷 / PDF保存」ボタン、または Ctrl+P（Mac は ⌘P）。
3. 送信先を「PDFに保存」、用紙 A4、余白「既定」、「背景のグラフィック」をオン、「ヘッダーとフッター」をオフにして保存。書類ごとに自動で改ページされます。
4. 送付の順番の目安: ①提案書（06）→ ②セキュリティ基準書（05）→ ③基本契約（01）＋個別契約（02）＋保守仕様書（04）→ 署名 → 納品後に検収確認書（03）。
5. 電子契約サービス（クラウドサイン、GMOサイン、freeeサイン等）を使う場合は、PDF をそのままアップロードし、甲乙の署名欄に署名位置を置きます。

## 法的な注意

- 本テンプレートは実務でそのまま使える粒度で作成していますが、弁護士によるリーガルチェックの代わりにはなりません。初回の利用前と、取引の規模・業種が変わるときは、弁護士の確認を受けてください（ローンチ・クルーの T07 に含めてあります）。
- 消費税率、遅延損害金の利率、最低契約期間などは案件に合わせて JSON で変えられます。
- 顧客が消費者（個人）の場合、消費者契約法により免責条項の一部が無効となることがあります。個人顧客との契約では、損害賠償の上限条項を外す、または弁護士に確認してください。
