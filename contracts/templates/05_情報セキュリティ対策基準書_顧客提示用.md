# 情報セキュリティ対策基準書（お客様提示用）

**{{contractor_name}}** は、IPA（独立行政法人情報処理推進機構）「中小企業の情報セキュリティ対策ガイドライン」に基づき、お預かりする情報とお客様のシステムを守るため、以下の対策を実施しています。本書は、業務委託基本契約書第8条（個人情報の取扱い）の安全管理措置の内容を、お客様にわかりやすく説明するものです。

## 基本方針

1. **お客様の資産はお客様のもの。** サーバー・ドメイン・各種サービスは原則として**お客様名義**で契約し、当方は作業に必要な権限だけをお借りします。契約が終了しても、お客様がご自身のシステムを失うことはありません（「囲い込み」「人質化」をしません）。
2. **本番の個人情報を持ち出さない。** 開発・検証は匿名化データやダミーデータで行い、本番の個人情報を作業端末に保存しません。
3. **最小権限・多要素認証。** すべての管理アカウントで2段階認証を有効にし、必要最小限の権限で作業します。
4. **記録と報告。** 作業内容を記録し、万一の事故は速やかにご報告します。

## ① アカウント・インフラの管理

| 項目 | 対策 |
|---|---|
| 契約名義 | サーバー、ドメイン、決済、メール配信、外部APIなどは**お客様名義**で契約。当方は共同作業者・開発者権限の付与を受けて作業 |
| 権限の範囲 | 作業に必要な最小限の権限のみ。請求情報・契約者情報へのアクセスはお客様に留める |
| 2段階認証 | 当方の全アカウント（クラウド、GitHub、メール、パスワード管理ツール）で2段階認証を必須化。お客様の管理者アカウントにも有効化を依頼 |
| パスワード管理 | パスワード管理ツール（暗号化保管）で生成・保管。使い回し・平文での送付をしない。認証情報の共有はツールの共有機能または暗号化した経路で行う |
| 退任・終了時 | 契約終了時に当方の権限を削除し、当方が保持する認証情報を破棄。お客様にその旨を報告 |
| 認証情報の保管 | システムの秘密鍵・APIキーは環境変数またはシークレット管理機能に保存し、ソースコードに含めない |

## ② 開発環境と本番データの分離

| 項目 | 対策 |
|---|---|
| 環境の分離 | 開発（ローカル）・検証・本番を分け、本番への反映は確認を経て実施 |
| 本番データの取扱い | 本番の個人情報を作業端末へダウンロード・保存しない。調査に必要な場合はお客様の同意のもと、本番環境上で最小限の範囲を確認 |
| テストデータ | 開発・検証には匿名化データまたはダミーデータを使用 |
| 生成系ツールの利用 | 文章・画像・コードの生成補助ツールを利用する場合、お客様の個人情報・秘密情報を入力しない。学習に利用されない設定のサービスを選択 |
| 変更管理 | ソースコードはバージョン管理（Git）で履歴を保持。本番反映前に動作確認を行い、問題時は切り戻し可能な状態を維持 |

## ③ 通信・アクセス制御

| 項目 | 対策 |
|---|---|
| 常時SSL/TLS | 公開するすべてのページ・APIをHTTPS化。証明書の有効期限を監視し自動更新 |
| サーバーへの接続 | SSHは鍵認証（パスワード認証は無効化）。可能な範囲で接続元IPアドレスを制限 |
| 管理画面 | 管理画面は推測されにくいURL・強固なパスワード・2段階認証（可能な場合）で保護。試行回数制限を設定 |
| 通信の暗号化 | 認証情報・個人情報を含むファイルの受け渡しは、暗号化された経路（共有ドライブの権限付き共有、パスワード管理ツールの共有機能等）で行う。メール添付の平文送付はしない |
| 不要なポート・サービス | 使用しないポート・サービスは閉じる。公開範囲を定期的に点検 |

## ④ 作業端末の保護

| 項目 | 対策 |
|---|---|
| ディスク暗号化 | 作業端末の記憶装置を全体暗号化（BitLocker / FileVault 等）。紛失・盗難時も内容を読み取れないようにする |
| 画面ロック・認証 | 離席時の自動ロック、端末ログインの生体認証またはPIN |
| OS・ソフトの更新 | OS、ブラウザ、開発ツールを最新に保ち、セキュリティ更新を速やかに適用 |
| マルウェア対策 | OS標準またはそれ以上のセキュリティ対策ソフトを常時有効 |
| ネットワーク | 公衆Wi-Fi（カフェ・ホテル等の暗号化されていない無線LAN）での作業を禁止。外出先ではテザリングまたはVPNを使用 |
| 端末の管理 | 作業端末は当方の管理下にあるものに限定し、家族・第三者と共用しない。廃棄時はデータを完全消去 |

## ⑤ 事故対応と報告

1. 情報漏えい・不正アクセス・紛失等の事故またはそのおそれを認識した場合、**原則24時間以内**にお客様へ第一報を行います。
2. 被害拡大の防止（権限の停止、パスワードの変更、該当機能の一時停止）を最優先で実施し、原因調査と再発防止策をご報告します。
3. 個人情報保護委員会への報告・本人への通知が必要な場合、その判断と手続はお客様（個人情報取扱事業者）が行い、当方は必要な情報提供と作業で全面的に協力します。

## ⑥ IPA「SECURITY ACTION」への取り組み

当方は、IPAが推進する中小企業向けの自己宣言制度「SECURITY ACTION」の趣旨に賛同し、「情報セキュリティ5か条」（①OSやソフトウェアは常に最新の状態にしよう ②ウイルス対策ソフトを導入しよう ③パスワードを強化しよう ④共有設定を見直そう ⑤脅威や攻撃の手口を知ろう）を実践し、本書の対策を継続的に見直します。

> 宣言の段階（一つ星／二つ星）および宣言日は、当方の最新の状況をお伝えします。宣言は当方の自己宣言であり、第三者機関による認証ではありません。

## お客様にお願いしたいこと

- 管理者アカウントの2段階認証を有効にし、パスワードを他のサービスと使い回さないでください。
- 当方へ認証情報を送る際は、メール本文やチャットに平文で貼らず、当方が案内する共有方法をご利用ください。
- 退職者・担当変更があった場合は、該当アカウントの権限見直しをお知らせください。
- サイトに掲載する個人情報（お客様の声、写真など）は、ご本人の同意を得たうえでご提供ください。
