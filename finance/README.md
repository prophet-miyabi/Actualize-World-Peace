# 財務諸表（finance/）

AWP（個人事業・法人化準備中）の帳簿と財務諸表。仕訳帳 `journal.csv` と資金計画 `plan.json` から、損益計算書・貸借対照表（簡易）・月次キャッシュフロー・資金計画（300万円の目標との差）を生成します。

```bash
node finance/statements.js            # 今日までを集計 → finance/output/財務諸表_YYYY-MM-DD.md / .html
node finance/statements.js 2026-10    # 指定月の末日までを集計
```

## 記録のルール（数字を作らない）

- `journal.csv` の1行が1つの事実。`status` は `確認済`（明細で確認した）／`概算`（為替や按分を含む）／`要確認`（請求額が未確認）／`目標`（実績ではない）のいずれか。
- `kind`: `売上`（請求が立った）／`入金`（実際に入った）／`経費`／`出金`（経費以外の支払い）／`資産`（売掛金・備品など）／`負債`（買掛金・借入）／`資本`（元入金）。
- 概算・要確認の行は財務諸表に状態が表示されます。外部に提示する前に実額へ置き換えてください。
- 顧客名・金額を含むため `finance/output/` は Git に入れません（.gitignore 済み）。`journal.csv` 自体も、顧客名を含めるようになったらリポジトリを非公開に保つか、別管理にしてください。

## 口座開設後にやること

1. 事業用口座の開設日の残高を `資本`（元入金）として追加。
2. カード明細・Anthropic Console・Render の請求額で `概算` / `要確認` の行を実額に更新。
3. 受注したら `売上`（請求日）と `入金`（入金日）を分けて記録。
4. `plan.json` の `pipeline` に見込み案件（確度つき）を入れ、月初に生成して保管。
5. 法人設立時は、個人事業の資産・負債の引き継ぎを税理士に相談（ローンチ・クルーの T07/T30 と合わせて）。
