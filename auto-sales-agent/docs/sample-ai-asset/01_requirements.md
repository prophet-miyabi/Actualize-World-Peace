# LP要件定義書 — クオントフォリオ（架空）AI資産運用サービス

見本プロジェクト。社名・数値・声はすべて架空。実案件では金融商品取引法・広告規制の法務確認を前提とする。

## 1. プロジェクトの目的

- 目的: 「投資に興味はあるが、時間と知識に不安がある30〜50代」に、3分の無料診断（CV）を受けてもらい、口座開設へ進む見込み客を獲得する。
- 構成: 10セクションのハイブリッド型（新PASONA: 問題 → 親近感 → 解決 → 提案 → 絞り込み → 行動 ＋ BEAF: 実績 → 利点 → 強み → 特徴）。

## 2. KGI / KPI

| 区分 | 指標 | 目標（見本） | 計測 |
|---|---|---|---|
| KGI | 口座開設数（月） | 設定値 | 口座開設完了イベント |
| KPI1 | 無料診断の完了率（LP訪問 → 診断送信） | 3.0% 以上 | フォーム送信イベント（GA4 `generate_lead`） |
| KPI2 | 診断 → 口座開設 | 25% 以上 | CRM 側で突合 |
| KPI3 | ファーストビュー離脱率 | 55% 以下 | スクロール 25% 到達率 |
| KPI4 | CTA クリック率（位置別） | 固定CTA 2% / セクション末 1% | GTM クリックトリガー（ボタンIDごと） |
| 補助 | 悩みチェックのタップ数 | 平均2以上 | カスタムイベント |

| 項目 | 内容 |
|---|---|
| 属性 | 38歳・会社員・年収550万円・既婚・子1人。預金600万円のうち投資は0 |
| 顕在ニーズ | 「そろそろ投資を始めたい」「NISA を使いたい」「手数料が分かりやすいものがいい」 |
| 潜在ニーズ | 「失敗して家族に言えない事態を避けたい」「判断を誰かに任せたいが、丸投げは怖い」「途中でやめられる安心がほしい」 |
| 行動障壁 | 何から始めるか分からない／下がったときの自分が信用できない／手数料の全体像が見えない／解約が面倒そう |
| 決め手 | 事前に「最大どれくらい下がりうるか」が分かる／費用が1つだけ／人に相談できる／いつでも出金できる |

## 4. 技術仕様

- 形式: HTML＋Tailwind CSS（CDN）＋Alpine.js の1ファイル（`template_lp_drm.html`）。コピーは `brief.json` の `drm` から読み込み、文言差し替えはJSONだけで完結。
- レスポンシブ: 375px を基準に設計。比較表はスマホで横スクロール（最小幅560px）。
- モバイル追従CTA: 画面下に「無料診断」「LINEで相談」を常時表示。デスクトップは上部バーに主CTA。
- 表示速度: 画像は SVG とグラデーションで代替（写真を使う場合は WebP・遅延読込）。外部読込は Tailwind / Alpine / Google Fonts のみ。目標 LCP 2.5秒以下。
- EFO: フォームは2ステップ・4入力（目的・積立額は選択式、氏名・連絡先のみ入力）。必須が揃うまで送信ボタンを無効化。プライバシー文言をボタン直上に配置。
- 計測タグ: GTM 1本。イベント — `view_section`（各セクション到達）、`cta_click`（ボタンID: top / hero / sticky / closing）、`pain_check`（チェック数）、`form_step`（1→2）、`generate_lead`（送信）。LINE ボタンは `line_click`。
- 法規: 画面下部に重要事項（商号・登録番号・加入協会・リスク・手数料）。断定的な利益表現を使わない。数値には基準日を付ける。
